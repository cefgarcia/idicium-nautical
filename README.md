# Desafio Idicium — Nautical

Projeto desenvolvido como parte do desafio técnico da **Idicium**, utilizando o dataset **Nautical**.

## Objetivo

O desafio tem como objetivo demonstrar conhecimentos de análise de dados, SQL, modelagem, tratamento e exploração de dados, além da construção de análises e visualizações para apoio à tomada de decisão.

## Tecnologias utilizadas

* Python
* SQL
* PostgreSQL
* Power BI
* Jupyter Notebook
* Git e GitHub

## Estrutura do desafio

O projeto contempla etapas de:

1. Exploração inicial dos dados (EDA)
2. Identificação dos tipos de dados
3. Criação do schema no PostgreSQL
4. Carga dos arquivos CSV
5. Análise de clientes e categorias
6. Construção de dimensão calendário
7. Análise e previsão de demanda
8. Desenvolvimento de dashboard no Power BI

## Dataset

O dataset utilizado no desafio é o **Nautical**, composto por diferentes tabelas relacionadas a clientes, pedidos, produtos, pagamentos, estoque, categorias e demais entidades do negócio.

## Principais ferramentas

### Python

Utilizado para exploração dos dados, automação de tarefas e preparação das etapas do projeto.

### PostgreSQL

Utilizado para criação do schema, carga dos arquivos CSV e execução das consultas SQL.

### Power BI

Utilizado para construção do dashboard e apresentação dos principais indicadores e análises.

## Objetivo profissional

Além de atender ao desafio técnico, este projeto representa uma prática aplicada de **Engenharia e Análise de Dados**, envolvendo desde a ingestão e modelagem até a análise e visualização dos dados.
